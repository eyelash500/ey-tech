在當今 AI 爆發的時代，身為一個「一人開發團隊」，如何善用各種 AI 工具加速專案開發，同時又能兼顧**帳號額度效率**與**公司智慧財產權 (IP) 安全**？

這篇文章將分享我近期整理出的一套開發工作流，探討如何將 **Claude**、**Antigravity (AI Agent & IDE)** 以及 **Obsidian** 串聯起來，打造出極致且「公私分明」的開發體驗。

---

## 一、 釐清概念：AI Agent 與 AI IDE 的區別

許多人在剛接觸這些工具（例如新興的 AI 開發神器 Antigravity）時會感到困惑：「AI 助理（如 Antigravity Agent）和 AI 編輯器（如 Antigravity IDE）有什麼不同？只差在能不能在視窗裡看程式碼嗎？」

其實，兩者的角色定位截然不同：

* **AI Agent（大腦）**：它是負責思考與執行的主體。即使你不在特定的 IDE 內，它依然能透過工具讀取你的本機專案、在程式碼中搜尋關鍵字、直接修改檔案，甚至在你的授權下執行本機終端機指令（如 `npm install`、`git push`）。
* **AI IDE（辦公桌）**：它是給開發者（你）使用的視覺化介面。它將 Agent 寫好的程式碼即時呈現出來，讓你方便檢視檔案樹、進行語法高亮、手動微調，並提供網頁的即時預覽功能。

---

## 二、 多帳號環境下的「公私分明」工具鏈規劃

當我們同時擁有「公司帳號（通常為免費或入門方案）」與「個人帳號（如 Google AI Pro 等高級方案）」時，如果把私人的高級額度拿去跑公司專案，除了很快會把額度耗盡外，也會產生智財權與合規的灰色地帶。

因此，規劃出一套能發揮各家 AI 專長，且帳號界線分明的**雙軌開發工具鏈**，是現代開發者的必修課：

### 👤 軌道一：個人開發軌（使用個人 Pro / API 方案）

* **主力工具**：
  * **Antigravity CLI/網頁版**（綁定個人 Pro 帳號）：享受無限制的額度與強大模型，用來跑自己 Side Project 的專案初始化、程式碼生成與本機測試。
  * **VS Code (搭配個人 API Key)**：作為日常寫扣與微調的編輯器。
  * **Obsidian (搭配 Gemini API Key)**：作為本地知識庫，整理開發筆記、進行知識萃取與架構發想。
* **核心目的**：最大化個人 Pro 方案價值，專注於個人技術積累與 Side Projects 的敏捷開發。

### 🏢 軌道二：公司開發軌（使用公司授權/免費額度）

* **主力工具**：
  * **Claude Desktop / Claude Code CLI**（公司帳號）：負責高層次架構規劃、PRD（產品需求文件）撰寫與主要代碼設計。Claude 極佳的語意邏輯在這邊能發揮最大效益。
  * **Antigravity IDE**（公司 Starter 帳號）：只用作輔助性的微調、簡單 Bug 排查，或者根本不使用。
* **核心目的**：確保公司專案的程式碼留在公司授權的管道中。如果未來公司專案非常需要強大的本地 Agent 協作，應向公司申請企業授權，而非使用個人帳號頂替。

---

## 三、 給一人團隊的實戰建議

透過上述的工具分工，一人團隊也能展現出極高的戰鬥力：

1. **架構設計交給 Claude**：遇到新的需求時，先與 Claude 討論，由它協助產出架構設計、API 路由、以及 DB Schema 文件。
2. **實體開發交給 Agent**：將設計文件（Markdown 格式）丟進專案資料夾，並召喚具備本地讀寫權限的 AI Agent（如 Antigravity），由它接手「看文件、建檔案、寫程式碼」的髒活累活。
3. **做好帳號隔離**：在瀏覽器、CLI 與 IDE 中，隨時注意目前登入的 Email，確保公司專案不佔用個人額度，個人專案也不混入公司環境。

善用工具，做好分類，我們就能在 AI 時代的洪流中，從拼命趕路的「養馬人」，轉變為專注於決定方向的「駕駛員」！
