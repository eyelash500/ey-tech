不懂夏威夷？用 Vibe Coding 請 AI 建一個專屬旅遊網

年初做了一個有趣的 Vibe Coding 小專案，起因很蠢——我突然很想去夏威夷，但完全不知道夏威夷有什麼。 因為不瞭解，所以建立了一個網頁去學習 某天看新聞的時候，想到如果今年出國玩也不錯耶。但要去哪裡呢？那就去朝聖某個死神學開直升機的夏威夷。 不過…問題是…我對夏威夷完全不熟，只知道是美國的一部分，但又跟美國本土文化很不一樣。這樣的地方到底有什麼風土民情？到底可以去哪裡觀光？重要的是，要花多少錢呢？ 於是有這些問題，我就用 Vibe Coding 請 Gemini 幫我建立一個網站：2026 夏威夷阿囉哈冒險計畫，來解決我眾多的問題。 一開始我對於夏威夷很不熟悉，因此身為社畜的我，按照基本原則，既然要去，就要去得有意義又省錢，那就去旅遊的時候也參加他們的節日慶典吧！不只逛逛市集，也體驗一下他們的文化。因此我在網站賦予了觀光兼節日的屬性。 接著想到，社畜不能請太多假，會招來白眼，因此要求 AI 幫忙制定一個合理的天數以及旅遊預算，這樣我就可以知道要請多少天的假、準備多少的錢。甚至請 AI 幫我做出省錢計畫，避免我從夏威夷飛回來後要開始吃土。 媲美旅行社的網站與計畫，被現實擊敗 最後完成的 冒險計畫網站，花費我不到半天的時間，就做出可媲美旅行社網站（甚至覺得比很多旅行社厲害），儘管行程和規劃沒有他們那麼專業，但對於完全不知道夏威夷觀光的我，這就是個很好理解及協助規劃的網站。從這邊，我可以快速認識夏威夷一整年著名的節慶與活動，值得探訪的景點，甚至挖出不少原本不會發現的體驗行程。不只讓我對於夏威夷旅遊更嚮往，也使我對於旅行的成本更有概念。最重要的是，不用像以前一樣到處翻旅遊部落格、旅行社行程表，再自己整理成企劃書，全部由 Vibe Coding 就可以做出具有互動性，且資料（還算）齊全的網站，讓資訊收集與行程規劃變得一目了然。 但是計畫來不及變化，今年的我，沒有這麼大筆錢可以飛出去了…Q口Q 不過如果明年有機會，我就可以用 AI 把這個 2026 年計畫改良成更厲害的「2027 年夏威夷計畫」！至於能不能真的飛出去，就不是 Gemini 能解決的問題了。

我與 Vibe coding 的第一次相遇，用 Gemini 實踐想像

自從接觸 Gemini 的 Canvas 後，我對於它的強大輸出功能感到驚訝！ 只要給一個小小的藍圖與方向，它就能具現化腦海中的想像，呈現出的視覺美感甚至遠遠超過我的預期（我完全看不到車尾燈）！嚇到吃手手的我，立刻開始研究，到底發生了什麼事情，這到底是什麼神奇的魔法！深入了解後才發現，原來 AI 在 2025 年大躍進，這也催生出一個全新名詞—— Vibe coding（氛圍編碼）。 Vibe coding 實現腦中的想像 當我運用 Vibe coding，輕鬆地打造出想要的「情境」（也就是我想要的氛圍）時，腦中突然閃過一個大膽的念頭：既然如此，我是不是能輕易地將腦中那些複雜的想法與知識，全都化為網頁呢？ 說做就做！我立刻著手製作了 退休金缺口計算機。 Gemini 將「可以退休」這個遙遠的概念，運用視覺化的圖表與實際的數字呈現在我眼前。這使未來的財務藍圖變得具體，讓我對人生規劃有了更踏實的想像。 使用 Vibe coding 打造金融助理團隊 然而這麼強大的 Vibe coding 工具出現後，身邊居然鮮為人知？儘管我用力推廣但是效果有限。後來想到，既然每年都會參加 iThome 的鐵人賽，那不如這次（去年）的鐵人賽就用「Vibe Coding」參賽！於是乎，我開始打造 Gemini 系列教學－30 天打造你的 AI 客戶金融助理團隊。 只是，結果卻出乎意料，我居然在第 24 天斷更了…這次的鐵人賽遺憾地 宣 告 失 敗。 儘管如此，我還是按照計畫，把所有內容發布，藉此完成了一個簡單 AI 助理團隊的建立與學習。 而這，也成為我第一個真正由 AI 協助打造出的專屬團隊。
