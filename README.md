# 睫毛 Learn Notes

AI 時代的個人研究書房。記錄軟體工程、AI 工作流的心得。

🔗 https://eyelash500.github.io/ey-tech/

## 技術架構

| 項目         | 工具                          |
| ------------ | ----------------------------- |
| 靜態網站生成 | Hugo                          |
| 主題         | PaperMod                      |
| 部署         | GitHub Actions → GitHub Pages |
| 字型         | Manrope + Noto Serif TC       |
| 搜尋         | Fuse.js                       |
| 分析         | Google Analytics              |

## 本機開發

```bash
git clone git@github.com:eyelash500/ey-tech.git
cd ey-tech
git submodule update --init
hugo server
```
